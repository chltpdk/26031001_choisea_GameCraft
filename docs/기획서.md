# DEAD ZONE 게임 기획서
- 게임 : DEAD ZONE(데드 존)
- 작성자 : 최세아

## 개요
- 장르 : 2D 탑다운 슈팅 서바이벌 게임
- 게임 소개 : 플레이어가 좀비로 가득한 공간에서 총을 사용해 좀비를 처치하고 최대한 오래 생존하는 게임이다. 
			플레이어는 키보드로 이동하고 마우스로 조준 및 공격을 하며, 시간이 지날수록 강해지고 많아지는 좀비들을 상대해야 한다.
- 재미 요소 : - 사방에서 접근하는 좀비를 피하면서 공격하는 긴장감
			 - 좀비를 처치하고 생존 시간을 늘리는 성취감
			 - 시간이 지날수록 좀비의 수와 이동 속도가 증가하는 난이도 변화
			 - 일반 좀비와 빠른 좀비 등 서로 다른 특성을 가진 적을 상대하느 재미

## 게임 진행
1. 게임을 시작하면 플레이어가 기본 생존 공간에 등장 한다.
2. 플레이어는 키보드로 이동하고 마우스로 방향을 조준하여 총을 발사한다.
3. 좀비는 일정 시간마다 생성되며 플레이어의 위치를 추적한다.
4. 총알이 좀비에게 명중하면 피해를 주고, 체력이 0이된 좀비는 사망한다.
5. 생존 시간이 길어질수록 좀비의 생성 빈도와 이동 속도가 증가하며, 이후에는 빠른 좀비와 같은 특수 적이 등장한다. 
6. 좀비에게 공격 받아 플레이어의 체력이 0이 되면 게임이 종료된다.
7. 게임 종료 후 생존 시간과 처치한 좀비 수를 확인하고 게임을 다시 시작할 수 있다. 

## 조작
 - W : 위쪽 이동
 - A : 왼쪽 이동
 - S : 아래쪽 이동
 - D : 오른쪽 이동
 - 마우스 이동 : 공격 방향 조준
 - 마우스 왼쪽 버튼 : 총 발사 
 - R : 재장전 (가능한)
 - ESC : 일시정지
 
 ##플레이 Stage 
 이 게임은 명확하게 구분된 여러 스테이지 대신, 생존 시간이 길어질수록 난이도가 상승하는 웨이브 방식으로 진행된다.
 # Stage 1 : 생존 시작 (0 ~ 20초)
  - 기본 좀비가 적은 수로 등장한다. 
  - 플레이어가 이동과 공격에 익숙해지는 구간이다 
 # Stage 2 : 좀비 증가 (20 ~ 40초)
  - 좀비의 생성 빈도가 등가하고 이동 속도가 빨라진다
  - 여러 방향에서 접근 하는 좀비를 피하면서 공격해야 한다
 # Stage 3 : 위험 구간 (40 ~ 60초)
  - 좀비가 더욱 빠르게 접근하고 등장하는 수가 증가 한다
  - 빠른 좀비와 같은 특수 적이 추가되어 생존 난이도가 높아진다
 # Stage 4 : 무한 생존 (60초 이후)
  - 시간이 지날수록 좀비의 수와 속도가 게속 증가한다
  - 플레이어는 체력과 공격 기회를 관리하며 최대한 오래 생존해야 한다
  
각 Stage에서는 플레이어와 좀비의 이동, 총알 발사, 피격 및 사망 애니메이션이 발생하고 시간의 흐름에 따라 적의 생성과 이동 속도가 달라지므로 게임 화면과 진행 상황에 지속적인 동적 변화가 나타난다.
